# Instalação do MCI CRM

## Objetivo
Disponibilizar uma opção visível para instalar o MCI CRM no computador e no celular.

## Implementação
- Adicionar os dados oficiais do aplicativo e os ícones necessários para instalação.
- Ajustar o aviso existente para funcionar no computador, Android e iPhone/iPad.
- Exibir orientação adequada quando o navegador não oferecer instalação automática.
- Manter a prévia do Lovable sem registro de cache, preservando as notificações existentes.

## Validação
- Confirmar que o navegador reconhece o aplicativo como instalável na versão publicada.
- Conferir o aviso e as instruções em telas de computador e celular.

## Detalhes técnicos
Será usada instalação pela tela inicial do navegador, sem adicionar modo offline. O serviço de notificações existente será mantido separado.
